# Inventory — API modules

> Path prefix `backend/src/modules/`. Each module follows the anatomy in plan §11 (`http/`, `application/`, `domain/`, `infrastructure/`). Other modules may call only the **façade**.
> Paths are relative to `backend/`. `planned` evidence = plan section; `useful` evidence = module file + integration specs in `backend/test/integration/` (all passing 2026-10-09).
